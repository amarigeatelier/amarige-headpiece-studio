# このフォルダの使い方(グリーンバック写真→透過PNG)

グリーンバックで撮影したパーツ(花・リボン等)の写真から、背景を透明にしたPNGを作るための
フォルダです。`photo_correction` と同じ考え方で、スマホのOneDriveアプリからこのフォルダに
ドラッグするだけで、このPC上にも自動で同期されます。

---

## フォルダの役割

- `inbox/` — 透過にしたい、グリーンバックで撮った写真をここに入れる。
- `output/` — 透過済みのPNGがここに出力される。ファイル名は元のまま(拡張子だけ`.png`に統一)。
  管理画面の「カットアウト写真」「サイズ参考写真」「金具なし写真」欄には、ここから
  アップロードする。
- `inbox/processed/` — 処理が終わった元画像は自動でここに移動される(取り違え・重複処理防止)。

---

## 運用ルール

1. グリーンバックで撮った写真を `inbox/` に置く
2. `node scripts/remove-green-background.mjs`(または `npm run remove-green-background`)を実行する
3. `output/` に透過済みのPNGができるので、そこから管理画面にアップロードする

---

## 撮影のコツ(精度に直結します)

- **背景の縁の大部分が本物の背景色であること。** 縁全体の中で一番多い色を「背景色」と
  自動推定しているので、写真の縁の半分以上が台の金具や手などで隠れていると誤判定します。
  (花から離れた場所に写り込んだ小さなゴミ・糸くず程度なら自動で無視されるので問題ありません)
- **影を薄く。** 花を台紙から少し浮かせる、光を均一に当てる、など。影が濃すぎると、影の部分
  だけ透過しきれず残ることがあります。
- **緑被り(色移り)に注意。** 白・淡い色の花は縁が緑っぽく写っていないか、変換後の写真で
  時々チェックしてください(自動で軽減する処理は入れていますが、完璧ではありません)。

## 補足

- クロップは自動で行われます(花の形にぴったり合わせて余白を詰める)。
- 判定方法は「背景の色そのもの」に基づく方式なので、白背景用の`photo_correction`とは
  別の仕組みです。影がついて暗くなっても、色の系統(色相)が同じなら背景と正しく判定できます。
- 花の中心が黒に近い色(アネモネの中心など)の場合、暗すぎる部分は誤って消えないよう
  自動的に保護されます。
