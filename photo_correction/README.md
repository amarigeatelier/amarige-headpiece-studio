# このフォルダの使い方(パーツ写真の明るさ補正)

パーツ(花・リボン等)のカットアウト写真を、見本写真に近い明るさに補正するためのフォルダです。
`ai-note-system` の `data/media/photo_correction` と同じ考え方で、スマホのOneDriveアプリから
このフォルダにドラッグするだけで、このPC上にも自動で同期されます。

---

## フォルダの役割

- `reference/` — 見本(理想の明るさ)写真を置く場所。3〜5枚程度がおすすめ(枚数の上限はなし)。
  ここに置いた写真の平均の明るさを、補正の目標として毎回その場で計算します。
- `inbox/` — 補正したい新しいカットアウト写真をここに入れる。
- `output/` — 補正済みの写真がここに出力される。ファイル名は元のまま。管理画面へのアップロードはここから。
- `inbox/processed/` — 処理が終わった元画像は自動でここに移動される(取り違え・重複処理防止)。

---

## 運用ルール

1. `reference/` に見本写真がまだ無ければ、先に3〜5枚入れておく
2. 補正したいカットアウト写真を `inbox/` に置く
3. `node scripts/photo-correct.mjs`(または `npm run photo-correct`)を実行する
4. `output/` に補正済みの写真ができるので、そこから管理画面にアップロードする

---

## 補足

- クロップは行いません(すでに正方形の想定)。明るさのみの補正です。
- 画像全体(背景込み)の平均明るさで判断する方式です。背景を除外した判定はしていません。
- 色味(温かみ)の補正はしていません。必要になったら追加できます。
